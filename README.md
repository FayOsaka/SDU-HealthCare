## 📖 About The Project (เกี่ยวกับโปรเจกต์)

**SDU-Healthcare** คือระบบเว็บแอปพลิเคชันที่พัฒนาขึ้นเพื่อเพิ่มประสิทธิภาพการให้บริการของห้องพยาบาล มหาวิทยาลัยสวนดุสิต ระบบนี้ออกแบบมาเพื่อช่วยให้นักศึกษาและบุคลากรสามารถประเมินอาการเจ็บป่วยเบื้องต้นด้วยตนเอง และทำการจองคิวหรือนัดหมายเจ้าหน้าที่ล่วงหน้าได้ ลดความแออัดและลดระยะเวลาการรอคอยในห้องพยาบาล

### ✨ Key Features (จุดเด่นของระบบ)
- 🩺 **Symptom Checking:** ระบบประเมินและคัดกรองอาการเจ็บป่วยเบื้องต้น
- 📅 **Appointment Scheduling:** ระบบนัดหมายและจัดการคิวเข้าพบเจ้าหน้าที่ห้องพยาบาล
- 💊 **Medication Records:** การจัดการประวัติการเข้าใช้บริการและการเบิกจ่ายยา
- 📱 **Responsive UI:** หน้าจอใช้งานง่าย รองรับทั้งบนคอมพิวเตอร์และโทรศัพท์มือถือ

## 🛠️ Built With (เทคโนโลยีที่ใช้)

* **Frontend:** React, Tailwind CSS
* **Backend:** Node.js, Express.js
* **Database:** MySQL
* **Infrastructure:** Docker, Docker Compose

## ⚙️ Getting Started (การติดตั้งและใช้งาน)

### Prerequisites (สิ่งที่ต้องเตรียม)
ตรวจสอบให้แน่ใจว่าเครื่องของคุณติดตั้ง Node.js, npm และ Docker แล้ว
```bash
node --version
npm --version
docker --version
```
1. Clone repository นี้
```bash
git clone https://github.com/FayOsaka/SDU-HealthCare.git
```
2. เข้าสู่โฟลเดอร์โปรเจกต์
```bash
cd SUD-Healthcare
```
3. ติดตั้ง Dependencies ที่จำเป็น
```bash
pip install 
```
